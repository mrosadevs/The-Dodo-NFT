## ✨ Features

- 🏖️ **Animated Sand Background** — Real-time canvas particle system with sand-like textures
- 🖱️ **Custom Cursor** — Gold dot + ring that reacts to hover states
- 🎨 **Island Aesthetic** — Warm sand, gold, sky blue, coral, and teal palette
- 🪙 **Mint Section** — Prominent minting UI with collection details
- 📱 **Fully Responsive** — Works beautifully from mobile to ultrawide
- 🧈 **Buttery Smooth Animations** — Scroll-triggered reveals throughout
- 🔤 **Playful Typography** — Boogaloo, Fredoka One, and Nunito fonts

## 🛠️ Tech Stack

| Layer | Tech |
|-------|------|
| 📄 Markup | HTML5 |
| 🎨 Styling | CSS3 (Custom Properties, Animations, Gradients) |
| ⚡ Interactivity | Vanilla JavaScript |
| 🖼️ Fonts | Google Fonts (Boogaloo, Nunito, Fredoka One) |
| 🎆 Background | HTML5 Canvas API |
| 🖱️ Cursor | Custom DOM-based cursor system |

## 🚀 Getting Started

No build step — pure static HTML/CSS/JS.

```bash
# Just open it
open index.html

# Or serve locally
npx serve .
```
